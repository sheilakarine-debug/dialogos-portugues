Revisão Gramatical

This section helps to consolidate what you learned. Review the key grammar points from the podcast.

Imperativo Formal

Para dar sugestões a "você", "o senhor" ou "a senhora", trocamos as vogais:

Verbos em -AR (mudam para -E)

  • (Provar) → Prove uma francesinha.
  • (Atravessar) → Atravesse a ponte.
  • (Visitar) → Visite as caves.
  • (Apanhar) → Apanhe o elétrico.

Verbos em -ER / -IR (mudam para -A)

  • (Descobrir) → Descubra os azulejos.
  • (Viver) → Viva a noite.
  • (Perder-se) → Perca-se em Alfama.
  • (Beber) → Beba água de coco.

Foco: Imperativo (Irregulares)

Alguns dos verbos mais comuns são irregulares:

  • (Fazer) → Faça um cruzeiro.
  • (Ir) → Vá ao Porto.
  • (Ver) → Veja os passeios.
  • (Vir) → Venha a Lisboa.
  • (Trazer) → Traga um casaco.
  • (Pedir) → Peça um café.
  • (Seguir) → Siga em frente.

Palavras de Sequência

  • Primeiro, ...
  • A seguir, ...
  • Depois, ...
  • Finalmente, ...
